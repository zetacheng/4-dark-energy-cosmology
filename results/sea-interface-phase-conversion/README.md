# Sea-interface Phase-conversion Gate (`P4-SEA-01`)

A 5D Sea-interface model-enlargement test: does an explicit higher-dimensional
action support a healthy advancing Sea->lattice wall, a curvature-triggered
reverse transition, and a regular black-hole core — and can wall motion be
mapped to 4D cosmic expansion? Nine of ten sub-gates are constructible as an
EFT; the tenth (the expansion map) is the binding gap and is not fixed by the
minimal action.

Reproduce with:

```text
python -m scripts.sea_interface
python -m scripts.sea_bh_core
```

Outputs go to `regen/` (git-ignored); `raw/` is immutable. Operating point and
headline numbers: `config.json`, `processed/summary.md`. Verdict: `verdict.md`
(full text in `raw/sea_interface_verdict.txt`).
